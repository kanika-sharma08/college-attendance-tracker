# 📊 College Attendance Tracker

A simple Excel-based attendance tracking and visualization project designed to help students monitor subject-wise attendance and identify attendance levels at a glance.

This project was created as an independent data-management project to practice **Microsoft Excel, formulas, conditional formatting, and data visualization**.

## ✨ Features

* 📚 Subject-wise attendance tracking
* 🧮 Automatic calculation of total classes
* ➗ Automatic calculation of classes missed
* 📈 Automatic attendance percentage calculation
* 🚦 Automatic attendance status based on a 75% reference threshold
* 📊 Subject-wise attendance dashboard
* 🔎 Visual identification of low attendance
* 📉 Attendance chart for quick comparison
* 📌 Overall attendance summary

## 🛠️ Tools Used

* **Microsoft Excel**
* Excel formulas
* Conditional formatting
* Charts and data visualization
* Dashboard design

## 📋 Workbook Structure

### Attendance Data

The main worksheet contains:

| Field            | Description                |
| ---------------- | -------------------------- |
| Subject          | Name of the subject        |
| Classes/Week     | Scheduled classes per week |
| Weeks            | Tracking period            |
| Total Classes    | Automatically calculated   |
| Classes Attended | Number of attended classes |
| Classes Missed   | Automatically calculated   |
| Attendance %     | Automatically calculated   |
| Status           | Attendance status          |

### Dashboard

The dashboard provides:

* Total classes
* Total classes attended
* Overall attendance percentage
* Number of subjects below the reference threshold
* Subject-wise attendance table
* Attendance visualization

## 🧮 Example Formula

Attendance percentage is calculated using:

```text
Classes Attended ÷ Total Classes
```

The workbook also uses Excel `IF`, `SUM`, and `COUNTIF` functions for automated calculations and summaries.

## 🎯 Project Purpose

The purpose of this project was to gain practical experience in organizing data, creating automated calculations, applying conditional formatting, and presenting information through an Excel dashboard.

## ⚠️ Data Note

The workbook uses sample/tracking data for demonstration purposes. Attendance figures shown in the project should not be treated as official college attendance records.
